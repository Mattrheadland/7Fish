# 7Fish

Press **Cast**. 7Fish tells you whether to go fishing and what kind of fishing to do, from live weather, river, tide, buoy, moon and report data plus species and spot knowledge. Simple on the outside, thorough underneath.

Status: **planned, not built** (plan v1.1, Oct 14, 2026).

- `docs/PLAN.md`: architecture, data sources, engine, phases
- `docs/BRAND.md`: name, logo, color, type, voice
- `docs/REVIEW.md`: independent peer review and what changed
- `prompts/`: build, forecaster, validator, knowledge and calibration prompts

Start a build session with `prompts/00-build-orchestrator.md`, Phase 0.
